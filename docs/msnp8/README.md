# MSNP8 実機解析資料

このディレクトリには、Windows XP + MSN Messenger 6.x (MSNP8) の実機を
escargot等の稼働中サーバーに接続してキャプチャした通信ログと、
そこから読み取れる仕様のメモを蓄積していきます。

## 構成

- `captures/` : Wiresharkのpcapng生データ(個人情報を含む場合はコミット前に要確認)
- `commands.md` : 確認済みコマンド一覧(随時更新)
- `auth-flow.md` : ログイン認証(MD5チャレンジレスポンス)の詳細
- `features.md` : 絵文字・ファイル転送・カメラ・音声など、MSNP8時点での機能有無の調査結果

## 記録フォーマット(推奨)

```
>>> クライアント→サーバー のコマンド行
<<< サーバー→クライアント のコマンド行
```

行の後ろに `#` でコメントを付けて、何をしているコマンドかを注釈すると
後でAdapter実装時の参照資料として使いやすくなります。

例:

```
>>> VER 1 MSNP8 CVR0        # バージョンネゴシエーション開始
<<< VER 1 MSNP8 CVR0        # MSNP8で確定
>>> CVR 2 0x0409 winnt 5.1 i386 MSNMSGR 6.2.0137 MSMSGS user@example.com
<<< CVR 2 1.0.0000 1.0.0000 1.0.0000 https://... https://...
```
